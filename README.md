# Setu — archived prototype

Setu was explored as a local bridge between Joplin and AI assistants. Development stopped on 2026-08-13 after confirming that Joplin Desktop 3.6 includes a native MCP server providing the project's core intended capability.

Use Joplin's maintained native MCP feature instead: <https://joplinapp.org/help/apps/ai_mcp/>

The repository preserves a small Rust security prototype and planning evidence for reference. It is not a supported product and should not be used as an alternative MCP server.

No secrets or private note data are included. See `.ai/00-project-index.md` for the closure decision and project history.
